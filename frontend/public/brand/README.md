# Thryft Shop brand assets

Drop the three brand images in this folder with EXACTLY these names (the app
references these paths; until they exist the UI falls back to a plain glyph):

| File | What it is | Used for |
|------|-----------|----------|
| `logo-mark.png` | The cart mascot icon (square, no text) | Sidebar tile, login dialog, favicon |
| `logo-full.png` | Tag mascot + "Thryft Shop" stacked wordmark | Marketing / splash use |
| `wordmark.png` | "Thryft Shop" text-only wordmark | Headers / marketing use |

Upload via GitHub → this folder → **Add file → Upload files**, or commit them
locally. PNG with transparent or cream background; the mark is shown ~36 px
square in the UI, so any size ≥ 256×256 is plenty.
